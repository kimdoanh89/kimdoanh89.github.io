# Repository instructions

## No AI-generation attribution

When generating code, commits, or pull requests in this repository, never mention that the work is AI-generated:

- No "Co-Authored-By" trailers referencing Claude, an AI, or an assistant.
- No "Claude-Session" or similar session-link lines in commit messages.
- No "Generated with Claude Code" or "🤖 Generated with..." footers in commit messages or pull request descriptions.
- No code comments stating something was AI-generated (e.g. "// Generated by AI", "<!-- AI-generated -->").

Commits and PRs should read as written directly by the repository owner: plain, descriptive messages with no mention of the tooling used to produce them.
